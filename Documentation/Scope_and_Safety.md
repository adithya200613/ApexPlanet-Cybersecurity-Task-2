# Scope, Authorization and Safety
- Target is the student's own Metasploitable2 virtual machine.
- Network is VirtualBox Host-Only and isolated from public/campus networks.
- Active reconnaissance, scanning and packet generation are restricted to this lab.
- Passive research uses example domains or assets owned/authorized by the student.
- No credential harvesting, exploitation, persistence, data destruction or denial-of-service against third parties.
- Use dummy credentials for FTP visibility demonstrations.
- Sanitize screenshots and PCAP files before uploading.
- Stop testing if traffic reaches an unintended network or system.

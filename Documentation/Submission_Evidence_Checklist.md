# Task 2 Submission Evidence Checklist

Tick an item only after completing it and saving genuine evidence.

## Reconnaissance
- [ ] WHOIS output for an authorized/example domain
- [ ] Nslookup output
- [ ] Safe Google search-operator example and observation
- [ ] Shodan observation for an owned/authorized asset or documented safe example
- [ ] Authorized lab ping sweep result
- [ ] Banner-grabbing result from a lab service

## Nmap
- [ ] TCP SYN scan output (`-sS`)
- [ ] UDP top-ports scan output (`-sU`)
- [ ] Service/version scan output (`-sV`)
- [ ] OS detection output (`-O`)
- [ ] Nmap report with target, commands, results and interpretation

## Vulnerability scanner
- [ ] GVM/OpenVAS or Nessus setup evidence
- [ ] Target configuration showing lab target
- [ ] Completed scan status
- [ ] Exported vulnerability report
- [ ] Severity counts copied from actual report
- [ ] Analysis of important findings and remediation

## Wireshark
- [ ] HTTP traffic capture/filter
- [ ] FTP traffic capture/filter using dummy credentials
- [ ] DNS traffic capture/filter
- [ ] SYN packet analysis or clearly labeled sample-PCAP analysis
- [ ] Redacted screenshots and sanitized PCAP

## Firewall
- [ ] Initial iptables rules
- [ ] Allow rule
- [ ] Deny rule
- [ ] Before/after authorized scan evidence
- [ ] Cleanup/restore evidence

## Final submission
- [ ] Consolidated report updated with actual findings
- [ ] Screenshots named clearly and placed in folders
- [ ] No passwords, tokens, personal browsing or sensitive packet data
- [ ] Five-minute demo video recorded
- [ ] Video link tested in a private/incognito browser as appropriate
- [ ] GitHub README updated
